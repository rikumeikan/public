# public

画像を置いて、URL で見せるための場所。**ここに置いたものは誰でも見られる。**

一覧: https://rikumeikan.github.io/public/

## 上げ方

自分のスマホか PC で、GitHub にログインしてこのリポジトリを開き、
「Add file → Upload files」で画像をドラッグ → 「Commit changes」。

**画像はリポジトリの一番上（このファイルと同じ階層）に置く。** 一覧ページはそこだけを見ている。

## 見せ方

人の PC で見せるときはログインしない。URL を開くだけでよい。

| 見せたいもの | URL |
|---|---|
| 一覧 | `https://rikumeikan.github.io/public/` |
| 画像だけ | `https://raw.githubusercontent.com/rikumeikan/public/main/<ファイル名>` |

一覧の各画像の「URL」ボタンで、画像だけの URL をコピーできる。

## 上げる前に

- **写真の位置情報を消す。** iPhone なら共有の「オプション」で「位置情報」をオフ。スクリーンショットなら入っていない
- **人の情報が写っていないか見る。** 業務委託先の画面などが写り込んでいないか
- **消しても履歴に残る。** 本当に消したいものが出たら、リポジトリごと作り直す
